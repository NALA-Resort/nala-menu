Placeholders
<menu> Tonight's menu link, unique per guest, in invitation templates. Added on its own last line if left out. A link must be the last thing in the message or iPhones will not show the preview card, so it is moved there on save.
<form> The guest's pre-arrival form link, unique per booking, in pre-arrival templates. The same rules: added last if left out, moved last on save.
<first> The guest's first name, off the booking. Coming later — new placeholders appear in this legend as they are built.
Every message should name the resort: senders are required to identify themselves. Web addresses cannot be typed into a template; the only links that go out are the ones the placeholders build.
